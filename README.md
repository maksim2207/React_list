# React Listing Component (TypeScript)

Учебный проект по React и TypeScript. Компонент `Listing` отображает список предложений (карточек товаров) на основе данных в формате JSON с форматированием названий, цен и остатков на складе.

## 🚀 Технологический стек

* **React 18 / 19** (Функциональные компоненты, TSX)
* **TypeScript** (Строгая типизация props и структур данных, без использования `any`)
* **Vite** (Инструмент сборки)
* **CSS3** (Стилизация карточек, Flexbox-сетка и цветовые метки остатков)

## 📋 Функциональность компонента `Listing`

Компонент принимает проп `items` (массив элементов каталога) и производит следующую обработку:

1. **Проверка корректности данных**: Игнорирование неполных позиций (без обложки `MainImage`, названия `title` или цены).
2. **Обрезание заголовков**: Если длина названия товара превышает 50 символов, оно обрезается до 50 символов с добавлением специального символа троеточия `…`.
3. **Форматирование цены и валюты**:
   * `USD` — отображается со знаком `$` (например, `$15.99`)
   * `EUR` — отображается со знаком `€` (например, `€5.00`)
   * Прочие валюты — отображаются в формате `КОД Цена` (например, `GBP 2.50`)
4. **Индикация остатка товара (`quantity`)**:
   * `quantity <= 10` — класс `level-low` (красный бейдж)
   * `quantity <= 20` — класс `level-medium` (оранжевый бейдж)
   * `quantity > 20` — класс `level-high` (зелёный бейдж)
